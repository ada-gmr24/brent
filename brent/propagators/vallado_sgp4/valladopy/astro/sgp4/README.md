# Lunisolar Corrected & Lunar-Only Corrected Hujsak SGP4 Implementations

Please not that `lunisolar.py` denotes the SGP4 implementation that incorporated Hujsak-derived corrections for the lunar and solar effects. This implementation resulted in larger long-period variations and was later abandoned, however is retained for comparison studies.

Please refer to `deep_space.py` for the lunar-corrected SGP4 implementation that is now being used in this repository for future work and analyses.
